# Using Peek

Run `peek` to open it.

Most things are keyboard-controlled. Press `?` inside Peek to see the available shortcuts.

## settings

Peek has two settings: Language and Launch Intro.

## opening apps

Press `o` on a supported installed app or Homebrew cask to open it.

## uninstalling

```sh
peek gtfo
```

Peek will ask before removing anything.

That's about it.
